## Supervision 库

Supervision是一个专门用于计算机视觉任务的高级库，特别适合目标检测、跟踪和可视化。

### 🎯 核心功能

#### 1. 目标检测和跟踪
```python
import supervision as sv

# 初始化跟踪器
tracker = sv.ByteTrack()
tracker.reset()

# 从YOLO结果创建检测对象
detections = sv.Detections.from_ultralytics(yolo_result)

# 应用NMS（非极大值抑制）
detections = detections.with_nms(threshold=0.5, class_agnostic=True)

# 更新跟踪
detections_with_tracks = tracker.update_with_detections(detections=detections)
```

#### 2. 关键点检测
```python
# 从YOLO结果创建关键点对象
keypoints = sv.KeyPoints.from_ultralytics(yolo_result)

# 访问关键点坐标和置信度
xy_coords = keypoints.xy[0]  # 形状: (N, 2)
confidence = keypoints.confidence[0]  # 形状: (N,)

# 过滤低置信度关键点
mask = confidence > 0.5
valid_keypoints = xy_coords[mask]
```

#### 3. 边界框操作
```python
# 扩展边界框
expanded_boxes = sv.pad_boxes(xyxy=detections.xyxy, px=10)

# 获取边界框中心点
center_points = detections.get_anchors_coordinates(anchor=sv.Position.BOTTOM_CENTER)
```

#### 4. 可视化工具
```python
# 创建各种标注器
box_annotator = sv.BoxAnnotator(color=sv.ColorPalette.from_hex(['#FF0000', '#00FF00']))
label_annotator = sv.LabelAnnotator(text_color=sv.Color.WHITE)
ellipse_annotator = sv.EllipseAnnotator(color=sv.ColorPalette.from_hex(['#FF0000']))

# 在图像上绘制
annotated_frame = box_annotator.annotate(frame, detections)
annotated_frame = label_annotator.annotate(annotated_frame, detections, labels)
```

#### 5. 颜色和样式
```python
# 颜色定义
colors = ['#FF1493', '#00BFFF', '#FF6347', '#FFD700']
color_palette = sv.ColorPalette.from_hex(colors)

# 创建颜色查找表
color_lookup = np.array([0, 1, 2, 3])  # 对应不同类别的颜色索引
```

## Ultralytics 库

Ultralytics是YOLO模型的官方实现，提供简单易用的API进行目标检测和关键点检测。

### 🎯 核心功能

#### 1. 模型加载和推理
```python
from ultralytics import YOLO

# 加载预训练模型
model = YOLO('yolov8n.pt')  # 加载预训练模型
model = YOLO('path/to/custom.pt')  # 加载自定义模型

# 设置设备
model = model.to('cuda')  # 使用GPU
model = model.to('cpu')   # 使用CPU

# 单张图像推理
results = model('image.jpg')

# 视频推理
results = model('video.mp4')

# 批量推理
results = model(['img1.jpg', 'img2.jpg'])
```

#### 2. 推理参数控制
```python
# 基本推理参数
results = model(
    source='image.jpg',
    conf=0.5,        # 置信度阈值
    iou=0.45,        # NMS IoU阈值
    imgsz=640,       # 输入图像尺寸
    device='cuda',   # 设备
    verbose=False    # 是否显示详细信息
)

# 只检测特定类别
results = model(source='image.jpg', classes=[0, 1, 2])  # 只检测类别0,1,2
```

#### 3. 结果处理
```python
# 获取检测结果
result = results[0]  # 第一张图像的结果

# 访问边界框
boxes = result.boxes
xyxy = boxes.xyxy  # 边界框坐标 (x1, y1, x2, y2)
conf = boxes.conf  # 置信度
cls = boxes.cls    # 类别ID

# 访问关键点
keypoints = result.keypoints
xy = keypoints.xy  # 关键点坐标
conf = keypoints.conf  # 关键点置信度

# 访问类别名称
names = result.names  # 类别ID到名称的映射
```

#### 4. 模型训练
```python
# 训练模型
model.train(
    data='dataset.yaml',  # 数据集配置文件
    epochs=100,           # 训练轮数
    batch=16,             # 批次大小
    imgsz=640,            # 图像尺寸
    device='cuda'         # 设备
)

# 验证模型
metrics = model.val()

# 导出模型
model.export(format='onnx')
```

### 🔧 项目中的实际应用

```python
# 在Tracker类中的使用
class Tracker:
    def __init__(self, model_path, nms_threshold=0.5):
        self.model = YOLO(model_path)
        self.nms_threshold = nms_threshold
    
    def detect_frames(self, frames, batch_size=12):
        detections = []
        for i in range(0, len(frames), batch_size):
            batch = frames[i:i+batch_size]
            results = self.model(batch, verbose=False)
            detections.extend(results)
        return detections
```
